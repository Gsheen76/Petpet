# Pet陪它 v1.7.4

本次为体验打磨与全面加固版本：宠物面板查看/陪伴分离、送礼反应、聊天搜索与陪伴周报上线；一套全应用审计带来的数据安全与稳定性修复（存档原子写入、聊天卡顿根除、自动睡醒回归等十一项）。

## 宠物面板与礼物

- **「查看 / 陪伴」分离**：点头像卡只切换查看对象——简介、待机动画、套装、送礼、改名全部跟随查看的宠物；点「陪我」键才真正切换出勤小狗。改名不再误改出勤宠物、送非出勤宠物不再由出勤宠物替演反应。
- **名牌 / 陪我键 / 改名组件素材化**：胶囊名牌（28 号名字居中）+ 狗头图标改名键（常驻）+ 定稿陪我键，全套用户素材落位；好感升级时面板即时提示。
- **送礼反应**：送出成功时出勤小狗当场播放开心动画（仅送出勤宠物时表演）。
- **礼物排版统一**：面板礼物页三列恒等宽（占位补齐空列，一行不再偏右），滚动条常驻；送礼确认弹窗按 Esc / 点卡片外一律视为取消——不再误触送出消耗礼物。

## 聊天与记忆

- **聊天搜索**：聊天窗标题下新增搜索框，按关键词即时过滤历史记录。
- **陪伴周报**：记录页顶部新增陪伴周报卡片（汇总互动数据）。
- **长期记忆抽取移入后台**：此前在长会话（历史存满 60 条）后，每发一条消息都可能卡顿最长 20 秒；现在抽取在后台线程完成，界面全程流畅。
- **档案不再自我污染**：分栏渲染文本被反复迁回「其他」栏、挤掉真实记忆的问题根除。
- **对话异常兜底**：AI 回复流出现任何内部异常时如实报错收场，输入框不再永久卡在「停止」状态。
- 离线兜底回复恢复随机多样性（此前恒返回第一条）。

## 稳定性与数据安全（全应用审计修复）

- **存档原子写入 + 自动备份**：进度保存改为「临时文件 + 校验落盘 + 原子替换」，写盘前保留上一份完好存档（`.bak`）；断电、崩溃、磁盘故障不再导致整档清零，主档损坏时启动自动回退备份。
- **自动睡醒回归**：精力过低时小狗自己走去角落睡觉、睡饱后自动醒来——该状态机自 v1.5.0 重构起意外失效，本版重新接线修复。
- **家具拖拽边界修复**：位置钳制改从家具定义目录读取尺寸（单一事实源），2026-09-10 后新增的 8 件家具不再能被整体拖出全景外。
- **宠物详情面板**：待机动画帧加载失败后切换不再造成定时器累积（动画倍速异常）根除。
- **小游戏加固**：小游戏中心、金币雨、幸运爪爪全部按键接入全应用统一悬浮/按住反馈；金币雨截止后的迟滞点击不再计分加币。

## 家园

- **遮挡滞回带二次校准**：按发布后回收的实测日志，临界滞回带宽 6px → 12px——宠物在家具底线附近 ±10px 内晃动不再来回闪层。

## 工程内部

- 家具拆分器尺寸改读定义目录、三处分栏托盘构建收敛为 `_build_chip_bar`（技术债清偿）。
- 全量 **882** 项自动化测试通过；GitHub Actions 每次 push 自动回归。
