# Pet陪它 v1.7.3

本次为修复与体验打磨版本：家具整套扩充重制、状态卡重新设计、长期记忆提醒上线、内存减半、闪退根除。

## 家具与小屋

- **家具扩充（8→12 件）**：复古圆挂钟（墙面装饰）、猫爬架、宠物软垫小床、木质小摇椅；全部家具按新画风整套重制。
- **抠图管线升级**：接触阴影吸收算法——AI 生成图家具脚下的浅色残晕不再残留；引擎统一绘制接地软阴影，家具「落地」不再漂。
- **购买家具默认进收纳**，从装修模式自行摆放（默认位已记录，放置即落位）。
- **装修面板滚动**：家具多了不再截断，滚轮浏览 + 右缘滚动条。
- **遮挡体验**：按脚底线 2.5D 排序；拖拽中的家具置顶显示；临界 ±6px 滞回带消除层级闪烁；挂钟等墙面件垫底层。
- **商店家居页分栏**：全部 / 家具 / 装饰 / 玩具，与装修面板同源。

## 状态卡

- 换成与家具同风格的**暖木挂牌**（用户定稿素材）：挂钉、骨头与爪印装饰、三条凹槽。
- 饱腹 / 心情 / 精力进度条实时画进凹槽；文字按最终显示分辨率栅格化，缩放不糊。
- 不再显示百分比数字与宠物名（按用户定稿）。

## 聊天与记忆

- **生日 / 纪念日主动提醒**：档案「重要的事」里「生日/纪念日/周年 + 公历几月几日」的条目到期当天主动祝贺（每条重要的事当天只提一次）。
- 搭话池新增**四季话术**与**公历节日问候**（元旦 / 情人节 / 劳动节 / 儿童节 / 国庆 / 圣诞；不做农历换算）。
- **聊天记录导出 txt**（聊天窗「导出」键，默认存文档目录）。
- **档案六栏导入 / 导出 JSON**（导入后仍需保存生效）。
- 聊天回复**单段不换行**（用户定稿）；午餐肉头像恢复整身原版且耳尖完整入框。

## 性能与稳定

- **内存减半**：姿势 / 动画帧按显示预算预缩，实测 347MB → 174MB。
- **落地弹跳顺滑**：连续碰撞消除触底停顿；喊疼气泡与落盘挪出碰撞帧；触底音效移除（用户反馈）。
- **闪退根除**：升级飘字气泡无引用被 GC 回收后定时器悬空（Qt 层访问违例，三天三次）——类级保活修复；新增原生崩溃转储双保险。
- 右键菜单悬浮跟手优化（成就扫描/贴图缩放缓存、悬浮当帧重绘）；新按键统一胶囊风格。
