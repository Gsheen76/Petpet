# Pet陪它 v1.7.1

> 发布日期：2026-09-10　|　上一版本：v1.7.0　|　主打：礼物系统 + 游戏中自动隐藏 + 右键菜单全新图标

## 更新亮点

- **礼物系统**：商店新增「礼物」页——三档价位（小小心意 80 / 真挚款待 200 / 豪华大礼 480 Pet币）每档三选一，共 9 种手绘风礼物，全部宠物中性（后续新宠物可直接沿用）。买礼物进背包，到宠物详情面板的新「礼物」分栏送出即可涨好感；每只小狗每档各有最爱礼物，送中最爱好感 ×1.5，面板内悬浮即可看到最爱标记。
- **送礼成就**：新增 7 项梯度成就（购买 3 项 + 送出 4 项），从「第一份心意」一路到「最好的伙伴」（送礼 40 次）。
- **游戏中自动隐藏**：检测到其他游戏在前台运行（全屏或来自 Steam / WeGame 等游戏平台目录）时，小狗会自动藏起不挡视线，游戏退出后自动回来；设置页新增「游戏中自动隐藏」开关，默认开启。
- **右键菜单全新图标**：三页共 18 个按键全部换上哑光奶油贴图，图标即按键——界面更干净，悬浮时放大并显示功能名称。
- **待机更从容**：饱腹 / 精力 / 心情的消耗速度整体下调，无强化时满值约可待机 2 小时，「持久活力」强化升满约 4 小时。

## 界面细节

- 商店顶部页签栏换用 5 槽新素材，与「宠物 / 套装 / 家居 / 强化 / 礼物」五个页签一一对应；礼物页四分栏复用经典 4 槽药丸素材。
- 商店与礼物页滚动条统一贴边展示，内容区宽度全页一致。
- 聊天中的宠物头像改为大头照特写，表情清晰可见。
- 宠物详情面板简介页新增「偏好」栏，一眼看清这只小狗最爱的三种礼物。
