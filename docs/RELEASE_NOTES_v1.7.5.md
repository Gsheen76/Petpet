# Pet陪它 v1.7.5

本次为每日玩法与陪伴数据版本：每日任务、连续签到、独立「每日」窗与陪伴热力日历上线；一套窗口稳定性根治（闪退家族修复 + 后台诊断日志）。

## 每日玩法（全新）

- **每日任务**：每天三条日常（摸摸/喂饭/陪玩/聊天/送礼五选三，按日期全员同题），做互动自动累计进度；每条完成可领 20 Pet 币，三条全领再领 30 全勤奖励。任务完成那一刻小狗会当场提醒你去领；可领任务 ≥2 时有「一键领取全部」。
- **连续签到**：7 天阶梯奖励循环（15/20/25/30/40/50/**80**），第 7 天大奖后回到第 1 天但连续天数继续累计；断签重新开始。连到 7 的倍数天有小狗特别庆祝。
- **独立「每日」窗**：右键主菜单新增「📅 每日」专属键（可领时亮红点），直达签到 + 日历 + 今日任务；托盘菜单同步补「每日 / 温馨记录」入口。
- **零点自动刷新**：任务与签到在本地零点一到即自动重置（红点即时亮起、开着的每日窗当场重建）；宠物可见时会说一句「零点啦，新的一天！来签到吧～」。

## 陪伴数据（全新）

- **七日互动柱状图**：记录页新增最近 7 天互动量柱状图（今日珊瑚高亮、柱顶计数）。
- **陪伴热力日历**：每日窗的月历升级为热力图——没签到的日子底色按当天互动量四档渐暖，「哪天陪得多」一眼回望；右下角图例说明。
- **周报活动文案**：陪伴周报新增「本周互动 N 次 · 最活跃 周X」「已连续活跃 N 天，TA 都记着呢」。

## 宠物更「活」了

- **心情贯穿四层表现**：心情低落时——只演求陪伴的小剧场、做想念的梦、主动搭话变黏人（既有：弹出「陪我玩」气泡）；心情好则元气满满。
- **小剧场彩蛋**：久置闲时（约 20 分钟冷却）随机表演一段小动画配台词（「看我！我会翻跟头哦——好啦其实是转个圈～」）。
- **领取反馈**：签到/任务/全勤/成就领取时小狗当场说话 + 开心动画。

## 稳定性（闪退根治 + 后台日志）

- **窗口闪退家族根治**：一系列「关面板/换气泡时偶发闪退」的根因（无父原生窗口被提前回收，在途事件投递到已释放对象）全量清偿——五处窗口统一接入保活基类，并以静态扫描测试强制未来所有浮窗必须继承，杜绝复发。
- **右键菜单首次打开不全**：高缩放屏（125%）上首次右键菜单被系统压到 83% 尺寸的问题根治（预热方式重造）。
- **悬浮手感**：菜单按键命中区改为固定整格（不随悬浮缩放漂移）、高亮铺满整格；鼠标移出菜单后高亮即时清除。
- **后台诊断日志**：关键动作留痕（启动/菜单/面板），程序内部异常从「无声消失」变为「记录完整堆栈并继续运行」——下次出问题有据可查。
- 备份还原原子化（中途失败自动回滚不留混合态）；聊天发送即退出搜索过滤；单击定时器泄漏、云端接口限流（防刷）等一并修复。
- **多屏与自适应**：面板落位与尺寸全屏自适应（小屏收缩/负原点屏/大屏零改动）；拔插显示器/改缩放后窗口自动钳回有效屏。
