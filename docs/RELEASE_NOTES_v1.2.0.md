# Pet陪它 v1.2.0

这是一次以“动作、设置、更新与跨平台”为核心的功能版本。

## 主要更新

- 新增可扩展的逐帧动作动画引擎，首批实装走路和进食动画。
- 优化动作播放速度、尺寸、落点与帧切割效果，让小狗运动更自然。
- 重构“温馨设置”界面：经典滑动开关、清晰的数值步进器、五档聊天窗口尺寸。
- 确保设置修改能够真实生效，保存和恢复默认时界面与运行状态保持一致。
- 新增启动时自动检查更新，也可通过右键菜单或托盘主动检查。
- Windows 打包版支持下载新版本、校验文件、替换程序并自动重启。
- 完成 macOS Intel 与 Apple 芯片双架构构建、菜单栏入口、数据目录和更新分流基础适配。
- 重新整理项目目录，并让正式安装包排除动画制作源图等开发素材。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.2.0-windows.zip`。
- Apple 芯片 Mac（M1/M2/M3/M4 等）：下载 `Petpet-v1.2.0-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.2.0-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级说明

应用会保留原有配置、聊天记忆、养成状态与设置。Windows 用户也可以直接在旧版本中选择“检查更新”完成升级。
