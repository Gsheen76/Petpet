# Pet陪它 v1.3.2

本次更新加入可重复游玩的小游戏，并集中修复参数调试、聊天提示、动画时长和
Windows 更新链路中的体验问题。

## 主要更新

- 新增“小游戏中心”，包含“金币雨”和“幸运爪爪”两种 Pet 币玩法，可重复游玩。
- 小游戏接入成绩、最佳分数、累计局数和 Pet 币收入记录，并加入对应成就目标。
- 源码模式新增参数调试器，可实时调整桌宠尺寸、物理、动画 FPS、成长衰减和
  小游戏参数；调试配置独立保存，不影响正式发布版。
- 聊天界面统一使用设置中的字体大小；API Key 未配置时显示“未配置”和右上角
  红点提示，配置后状态会即时刷新。
- 优化桌宠底纹、字体可读性、多屏位置恢复和小狗显示稳定性。
- 喂食动画完整播放两轮后停止，进食行为恢复约 1.5 秒的正常时长。
- Windows 更新下载遇到 TLS 握手超时时会自动重试；连续失败时显示友好的网络
  提示，不再直接暴露 `_ssl.c` 原始异常。
- Windows 更新替换成功后在启动新版前清理备份文件，避免残留 `.backup-*` 文件。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.3.2-windows.zip`。
- Apple 芯片 Mac：下载 `Petpet-v1.3.2-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.3.2-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。

## 升级与数据

旧存档会自动补齐小游戏记录、最佳分数和调试配置字段，不会重置名字、等级、
经验、好感、Pet 币、设置、API Key 或聊天记忆。Windows 自动更新继续原位替换
`Petpet.exe`，用户数据稳定保存在 `%LOCALAPPDATA%\Petpet`。
