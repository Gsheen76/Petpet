# Pet陪它 v1.2.3

这是一次围绕“更新可靠性、跨电脑显示一致性和界面可读性”的维护更新。

## 主要更新

- Windows 自动更新会在原安装位置原子替换 `Petpet.exe`，不再把新版留在 `updata` 或其他更新子目录中运行。
- 更新完成后自动删除下载缓存、待更新文件、临时备份以及旧的 `update/updates/updata` 目录，安装目录最终只保留最新程序。
- 名字、等级、经验、陪伴天数、AI 记忆和全部设置继续保存在稳定的用户数据目录，更新程序不会覆盖养成数据。
- 为 Windows 打包版加入 Per-Monitor V2 DPI 清单，并固定小狗、卡片、按钮和窗口的像素尺寸，减少不同系统缩放比例造成的整体放大。
- 小狗状态卡、交互气泡和说话气泡使用独立放大的清晰字体；聊天窗口、托盘菜单、设置页和新手教程不受该倍率影响。
- 设置窗口整体扩大 20%，设置页字体默认值调整为 24；标题区域保持普通箭头光标且仍可拖动，关闭按钮使用手型光标。
- 重新校准新手教程排版，正文使用 28px，并更新右键操作说明。
- 删除长按右键打开详细属性页的触发功能；右键统一打开状态卡和五个快捷互动气泡。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.2.3-windows.zip`。
- Apple 芯片 Mac（M1/M2/M3/M4 等）：下载 `Petpet-v1.2.3-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.2.3-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级说明

Windows 用户可以直接运行新版，或在旧版中点击“检查更新”。v1.2.3 会保留原有养成数据，并在成功替换程序后清理旧更新目录。

如果旧版本曾经从 `update`、`updates` 或 `updata` 文件夹启动，v1.2.3 会尝试恢复到最初安装目录中的 `Petpet.exe`。升级前仍建议正常退出正在运行的小狗。
