# Pet陪它 v1.2.2

这是一次以“睡眠互动、更新安全和界面可靠性”为核心的维护更新。

## 主要更新

- 新增 12 帧慢速睡眠呼吸动画，保持稳定基线，并将睡姿大小调整为日常状态的 80%。
- 小狗睡着时，可以按住左键约半秒并左右晃动，将它温柔地摇醒。
- 同一时间只允许运行一只小狗；重复启动会唤回已经运行的实例。
- Windows 用户数据改为稳定保存在 `%LOCALAPPDATA%\Petpet`。
- 自动更新使用系统临时目录下载，并替换原位置的程序，不再从更新目录启动一只“全新的小狗”。
- 首次迁移会保留原有名字、等级、经验、陪伴天数、AI 记忆和所有设置，且不会覆盖已经迁移的新数据。
- 隐藏小狗时同步关闭说话、互动、奖励和右键气泡；隐藏期间不会继续生成浮动气泡。
- 右键互动画布支持点击屏幕其他位置自动收起。
- 扩大右键状态卡，为饱腹、心情和精力使用程序绘制的骨头、爱心和闪电图标，避免 Emoji 字体缺失。
- 调整状态名称、百分比和状态文案布局，确保文字完整显示。
- 改进 AI 精灵表拆分工具，兼容不能被网格整除的源图，并统一动画落点。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.2.2-windows.zip`。
- Apple 芯片 Mac（M1/M2/M3/M4 等）：下载 `Petpet-v1.2.2-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.2.2-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级说明

Windows 打包版会在首次启动 v1.2.2 时，把旧版程序旁的数据复制到稳定的用户数据目录。此后自动更新只替换程序文件，不会重置小狗。

建议保留旧版文件直到首次启动 v1.2.2 并确认名字、等级和聊天记忆均正常；迁移成功后即可正常使用应用内更新。
