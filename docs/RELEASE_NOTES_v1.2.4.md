# Pet陪它 v1.2.4

这次更新重点增加了更有参与感的动画互动、自动作息，以及更方便的 AI 聊天配置入口。

## 主要更新

- 新增 24 帧左键抚摸动画：点击小狗后会出现小手轻抚头部，小狗会开心回应，完整播放后回到正常状态。
- 重做“玩耍”为互动扔球场景：视角拉远后，小狗在远处正面等待；玩家可在区域内选择落点，3 秒未操作则自动投球。
- 小球与小狗使用同一条 24 帧时间线同步运动，小狗会真实完成蹲伏、蹬地、腾空、前爪伸出和张嘴接球，并在最终落点交会。
- 扑球动画调整为 14 FPS；接球后定格 1 秒，并显示“接住啦！”、爱心、星星和扩散光环庆祝效果。
- 新增自动作息：精力低于 30% 时，小狗会主动走到最近的屏幕底部角落睡觉；自动睡眠恢复到 80% 以上后会自己醒来。
- 自动睡眠增加“我困了”“午安/晚安主人”“睡醒啦，我又回来啦”等专属对白。
- 玩家手动触发的睡眠不会被自动作息唤醒；旧版本中已经处于睡眠的存档也会按手动睡眠处理。
- 移除随机出现的低精力“睡一会”气泡；饥饿和低心情气泡改为温馨胶囊样式，加入柔和渐变、小尾巴及不依赖表情字体的图标。
- 聊天窗口底部新增 API Key 配置、模型选择和清除记忆按钮；API Key 可直接保存在用户数据目录，无需手动寻找配置文件。
- 改进动画边缘、尺寸、透明背景和隐藏状态处理，并补充相关自动化测试。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.2.4-windows.zip`。
- Apple 芯片 Mac（M1/M2/M3/M4 等）：下载 `Petpet-v1.2.4-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.2.4-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级说明

从旧版本升级会继续使用用户数据目录中的名字、等级、经验、陪伴天数、设置、API Key 和聊天记忆。Windows 自动更新会替换原位置的程序文件，不会覆盖养成数据。
