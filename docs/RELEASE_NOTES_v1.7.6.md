# Pet陪它 v1.7.6

本次为手感、性能与陪伴体验大修版本：全局按键反馈与音效零延迟终版、商店/小屋/桌面全链路提速、第三个小游戏「记忆翻牌」上线、记录页陪伴度分数体系，以及一系列卡顿与闪退根治。

## 新玩法

- **第三个小游戏「记忆翻牌」**：4×4 图标配对（卡面用气泡菜单同款图标），按步数效率结算 Pet 币，完美通关 40 币；窗口与另两个小游戏同幅，入口在小游戏中心。
- **待机时长定稿**：正常待机 12 小时、升级完成后 24 小时（精力/饱腹/心情消耗速率放缓，旧存档自动迁移）。
- **每日键新图标与双态提醒点**：右键菜单「每日」换红色日历图标；提醒点双色——蓝色=今日任务还没做完，红色=有奖励可领（红优先显示）。

## 按键手感终版（全应用统一）

- **纯缩放反馈**：悬浮时按键放大、点击还原原大小——按压内缩、压暗、描边、白洗全部移除；四角「取景框」般的锁定特效根除。
- **全部按键都有统一点击音**（包括分栏页签）：可爱的软糖 pop 音，按下瞬间即响。
- **点击音零延迟**：音频改走常开推流通道，松开瞬间出声（此前在 Windows 上有约半秒的出声滞后）。
- **× 键全应用统一**：所有面板右上角 × 统一商店素材并保持宽高比（不再压扁），悬浮放大永不超出画布边缘。
- **分栏统一胶囊设计**：奶杏色底盘 + 浅珊瑚悬浮胶囊，已选中的分栏再点不会取消；聊天/档案/教程/设置等全部子页按键同步达标。
- 所有面板统一 850×960 尺寸，打开的页面大小一致。

## 性能大修

- **商店切换分栏提速**：页面缓存 + 图片后台预解码，切换从最长 2.6 秒降到几十毫秒，二次进入秒开。
- **小屋首开提速**：影子分析缓存化，首次打开从 3.4 秒降到 1.4 秒。
- **桌面待机更省电**：按动画帧率限频重绘，宠物待机时 CPU 占用约降 75%（约 20%→5%）。
- 音效预热等启动期一次性成本全部搬离操作窗口（此前首次切分栏可能冻结 5 秒）。

## 交互更跟手

- **长按才抓起**：单击=摸摸，长按或拖动=抓起，两者不再互相误触。
- **摸摸/摇醒卡顿根治**：点击反应窗口缩短、音效零阻塞、气泡窗口预建——动画不再慢放，台词不再播一半卡住。
- 宠物叫声（汪/吃饭/睡觉等）同样零延迟播放。

## 陪伴度分数

- **记录页总计升级为陪伴度分数**：不再只数摸了几次，而是按关怀程度加权（喂食、玩耍权重最高，聊天、摸摸、睡觉次之），每天有互动就有基础分。
- **四档等级**：无微不至 / 温暖用心 / 惦记着 / 匆匆一瞥；七日柱状图直接显示每天的分数，标题行显示今日等级。

## 稳定性

- **闪退根因再加固**：关闭面板瞬间在途窗口事件的残余时间窗封堵（「关面板偶发闪退」家族第六案）。
- **右键菜单点完就消失**、**每日窗/记录页打不开**、**菜单键首次悬浮迟一拍**等问题修复。
- **恐龙套装抓起/待机色差彻底校齐**：绿身/腹部/背鳍三区与待机完全一致，抓起前后是同一只。
- 恐龙套装走路阴影、家具描述行高、免费赠送素材尺寸等视觉细节打磨。
