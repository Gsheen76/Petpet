# Pet陪它 v1.6.2

本次更新把所有常驻面板统一到同一套视觉体系，重做了温暖记录的宠物维度，并接入全新的抓起动画，同时修复了两处交互卡顿。

## 主要更新

- 商店、成就、记录、设置、小游戏与聊天统一为同款暖色素材与 **850×960** 面板尺寸，所有窗口固定在屏幕中央打开。
- 温暖记录按小狗划分：新增“总计”页签显示共有数值；每只宠物独立页签展示自己的互动次数、相识天数、桌面陪伴时长与当前好感。
- 成就筛选合并为六个大类（全部/互动/聊天/游戏/换装强化/成长），界面更清爽。
- 购买确认弹窗支持 Esc 键和点击遮罩关闭。
- 设置页：三档偏好改为胶囊滑动选择并带悬浮/按压反馈；聊天字体档位调整为 小 20 / 中 24 / 大 26；移除聊天窗口大小设置（聊天窗口固定为面板尺寸）。
- 聊天：头像增大到 60px，字体统一为全局幼圆，历史区域透明展示爪印背景，助手的口播不再“汪汪”叫。
- 午餐肉新增**被提拎的撒娇晃动动画**：抓起小狗即播放晃动蹬腿的卖萌循环，颜色与待机对齐。
- 摇醒与抓起更流畅：拖拽动画常驻预加载，音效后端启动时后台预热，不再有瞬间的卡顿。
- 桌面小狗固定朝向（午餐肉面朝右、冰淇淋面朝左），走动不再左右翻转。
- 小屋可见视口调整为 700 宽，右下按钮左移，上弹菜单中心对齐圆形按钮。

## 下载

- Windows 可执行文件：`Petpet.exe`
- Windows 便携包：`Petpet-v1.6.2-windows.zip`
- Apple 芯片 Mac：`Petpet-v1.6.2-macOS-arm64.zip`
- 校验和：`Petpet-v1.6.2-SHA256SUMS.txt`

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级与数据

升级不会重置宠物名字、属性、好感、等级、经验、Pet币、家具、装扮、设置、头像、个人 API Key 或聊天记忆。Windows 用户数据保存在 `%LOCALAPPDATA%\Petpet`，macOS 用户数据保存在 `~/Library/Application Support/Petpet`。
