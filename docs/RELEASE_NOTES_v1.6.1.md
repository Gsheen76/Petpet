# Pet陪它 v1.6.1

本次更新带来商店与成就页的全新暖色视觉、家园操作菜单与画布调整、午餐肉桌面行走动画，并统一全局字体。自本版本起，安装包提供 Windows 与 Apple 芯片 Mac（arm64）两种版本，不再发布 Intel Mac 版本。

## 主要更新

- 全局界面字体更新为幼圆，聊天以外的游戏界面文字更加圆润可爱。
- 商店全面换装：素材化背景、分段标签栏、价格签、已拥有/使用中徽章、Pet 币胶囊和关闭按钮；卡片统一为暖黄风格并支持圆角裁剪。
- 商店家居与强化页滚动内容限制为两行四个模块，标题与简介固定在顶部不再随内容滚动，避免切页跳动。
- 成就页重构：与商店一致的背景和主题色，固定总览卡与分类筛选栏，按陪伴天数、互动、等级等前缀快速过滤。
- 商店、成就、记录和设置窗口打开时固定显示在屏幕中央，不再记忆上次的拖拽或滚动位置。
- 家园可见画布调整为更聚焦的宽度，世界保持原大小且相机自动跟随。
- 家园右下角改为两个圆形图标按钮：交互弹出抚摸、喂食、玩耍、睡觉；菜单弹出商店、装修、退出，两菜单互斥展开。
- 午餐肉获得桌面行走动画；冰淇淋的形象卡接入商店预览和聊天头像。
- 修复更换套装后家园行走素材不刷新的问题。

## 下载

- Windows 可执行文件：`Petpet.exe`
- Windows 便携包：`Petpet-v1.6.1-windows.zip`
- Apple 芯片 Mac：`Petpet-v1.6.1-macOS-arm64.zip`
- 校验和：`Petpet-v1.6.1-SHA256SUMS.txt`

自 `v1.6.1` 起仅提供 Windows 与 Apple 芯片 Mac 版本；Intel Mac 用户可继续使用 `v1.6.0` 及更早版本。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级与数据

升级不会重置宠物名字、属性、好感、等级、经验、Pet币、家具、装扮、设置、头像、个人 API Key 或聊天记忆。Windows 用户数据保存在 `%LOCALAPPDATA%\\Petpet`，macOS 用户数据保存在 `~/Library/Application Support/Petpet`。
