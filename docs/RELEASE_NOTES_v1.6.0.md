# Pet陪它 v1.6.0

本次更新加入完整的多宠物体验，并统一商店、聊天、桌面与家园中的宠物身份和动画表现。

## 主要更新

- 新增冰淇淋小狗：可在宠物商店购买和切换；每只宠物独立保存昵称、属性、位置与聊天记忆。
- 桌面和家园同步显示当前宠物，资源按宠物 ID 管理；冰淇淋桌面睡眠复用家园的 8 帧睡眠图，保持 3 FPS 与一致尺寸。
- 聊天头像和标题随当前宠物切换，支持“昵称（真实名）”显示；午餐肉使用活泼开朗的性格，冰淇淋使用温柔可爱的性格。
- 清理助手回复中的多余空行和横向空格，用户发送的原文保持不变。
- 商店宠物、套装、家具和强化卡片统一视觉；折扣显示原价删除线、现价与折扣，免费赠送置顶，家具保持双列完整信息。
- 强化互动恢复和消耗：抚摸、玩耍、吃饭和睡眠会随等级改善，满级时玩耍与睡眠消耗归零或按规则停止继续消耗。
- 修复快速右键双击菜单闪退、家园待机微小横移、睡眠尺寸过大、桌面拖拽待机图不同步和脚底阴影不匹配。
- 增强动画图集的尺寸、帧数、像素预算和损坏资源回退保护，避免异常资源造成内存或绘制问题。

## 下载

- Windows 可执行文件：`Petpet.exe`
- Windows 便携包：`Petpet-v1.6.0-windows.zip`
- Apple 芯片 Mac：`Petpet-v1.6.0-macOS-arm64.zip`
- Intel Mac：`Petpet-v1.6.0-macOS-intel.zip`
- 校验和：`Petpet-v1.6.0-SHA256SUMS.txt`

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级与数据

升级不会重置宠物名字、属性、好感、等级、经验、Pet币、家具、装扮、设置、头像、个人 API Key 或聊天记忆。Windows 用户数据保存在 `%LOCALAPPDATA%\\Petpet`，macOS 用户数据保存在 `~/Library/Application Support/Petpet`。
