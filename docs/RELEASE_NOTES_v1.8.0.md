本次为新宠物与新手指引版本：第三只宠物**棉花糖**（水彩小兔）全套装登场，新手教程从内容到美术全面重做（首次七页含选宠与命名、重看五页回顾），商业系统改为统一定价并由教程选宠授予初始伙伴。

## 新宠物：棉花糖 🐰

- **水彩画风的白色小兔**：竖长耳朵、软糯体态，家园与桌面双场景全套素材。
- **8 组完整动画**：待机（摆耳+眨眼，身体零漂移）、摸摸、喂食、玩耍（运镜）、挖宝、开心、睡觉，以及三段式抓起（挣扎摇晃→悬挂循环→落地回稳）。
- 全部动画经逐帧定位工艺处理（全帧体高并集归一、脚底钉同一条地线），动作间零跳变。
- 预置性格「温柔恬静、轻声细语」，专属礼物偏好（莓果篮/毛绒球/暖毯）。

## 新手教程全面重做

- **首次七页 / 重看五页分离**：新玩家走完整指引（认识伙伴→互动→菜单→小屋→聊天→选宠→命名），老玩家回顾只看玩法五页。
- **首次教程必读**：未完成不可关闭、不可跳过，走完选宠与命名才放行；重看模式随时可关。
- **选宠页**：三只伙伴同框，头像点选即看性格双四字词介绍与待机动画预览（三只统一体高、同一地线），外框尺寸锁定不随选择变化。
- **命名页**：为选中的伙伴取名字（≤6 字符），输入框常显「例如：团子、旺财、豆豆」示例，一键填默认名；顶部插图随所选宠物切换。
- **全套水彩美术**（AI 生成）：三宠合影主视觉、柔彩信笺背景、每页主题插图、随宠名牌图，统一粉彩绘本风。
- **重点词高亮**：操作动词与硬信息（单击/双击/按住左键拖动/右键等 16 个）珊瑚色加粗，正文纯排版严格统一。
