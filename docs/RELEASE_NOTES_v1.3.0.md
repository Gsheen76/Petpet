# Pet陪它 v1.3.0

这次大版本把长期陪伴数据、成长奖励和消费循环正式连接起来，并为后续可跟随
动画的 2D 装扮建立了清晰基础。

## 主要更新

- 新增“温馨记录”：统计相识时长、实际运行时长、Pet币收入与消费，以及抚摸、
  喂食、玩耍、睡眠、接球、聊天、摇醒、启动和升级等数据。
- 新增“暖心成就”：陪伴、互动、聊天、接球和等级目标达到后会出现红点，
  玩家可进入成就页手动领取 Pet币。
- 每升一级都会生成对应等级奖励；旧存档已有等级也可以补领。
- 新增 Pet币余额、收入和消费记录。首版收入以成就为主，后续小游戏和随机挖币
  可直接复用现有经济数据。
- 新增商店“装饰”和“强化”栏目。抚摸、喂食、玩耍、睡眠与成长速度均可强化
  5 级，价格逐级增加。
- 满级玩耍不再消耗精力和饱腹；满级睡眠不再消耗饱腹。属性强化不会额外直接
  赠送经验。
- 新增好感度等级和进度。抚摸、喂食、玩耍、接球、聊天、手动睡眠和摇醒等互动
  可提高好感；聊天可持续增长，其他互动使用独立冷却，避免重复刷取。
- 经验获取改为由好感度决定，并在成长卡中显示实时 `EXP/min`；饱腹、心情和
  精力不再直接改变经验速度。
- 新增免费的“暖心红项圈”，支持领取、装备和卸下。现阶段仅在可靠静止姿态
  显示，复杂动作期间自动隐藏，避免错误遮挡和漂移。
- 新增 2D 分层骨骼基础、清单格式和自动化测试，为后续全动作装扮挂点做准备；
  未完成的分层原画不会替换当前正式小狗。
- 整理运行素材和开发源图，移除废弃的 Blender 实验与多份中间精灵表。
- 将接球小球移动到独立运行时道具目录，并纳入 Windows/macOS 打包配置。
- 版本号集中到独立文件，Windows、macOS 和 GitHub Actions 使用同一来源。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.3.0-windows.zip`。
- Apple 芯片 Mac（M1/M2/M3/M4 等）：下载 `Petpet-v1.3.0-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.3.0-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时，可能需要
在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级与数据

从旧版本升级会继续使用原有用户数据目录，不会重置名字、等级、经验、陪伴天数、
设置、API Key 或聊天记忆。旧存档首次加载时会自动补齐记录、好感度、Pet币、
成就、强化和装扮字段。

Windows 自动更新仍会在原位置替换 `Petpet.exe`，用户数据稳定保存在
`%LOCALAPPDATA%\Petpet`。macOS 数据继续保存在
`~/Library/Application Support/Petpet`。
