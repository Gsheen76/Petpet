# Pet陪它 v1.7.0

> 发布日期：2026-09-07　|　上一版本：v1.6.3　|　主打：宠物详情面板全面重做 + 按键反馈全应用统一

## 更新亮点

- **宠物详情面板从零重做**：全新左栏宠物头像列表、居中宠物展示与改名牌，简介页以「图标 + 节名/数值」四模块（等级 / 好感 / 属性 / 性格）铺满排布，套装页左右分栏卡与穿装待机动画预览，进度数据一目了然。
- **简介/套装分栏按键**：素材化分栏牌精准吸附在内容卡边框上方，两键等大紧连；未选中降透明度区分当前页。
- **左下角购买提示框**：与宠物列表同宽的圆角提示框，提醒玩家宠物和套装可前往商店购买。
- **按键反馈全应用统一**（宠物面板 / 商店 / 家园 / 装修面板）：悬浮放大+白洗+珊瑚描边，按住内缩+压暗，松开在键内回弹 40ms 后才触发，拖出键外取消；规范已写入开发约定。
- **小屋菜单新增「宠物」键素材**：睡窝柴犬横幅插画，与商店/装修/退出键同族风格。
- **商店优化**：免费赠送 / 使用中 / 已拥有徽标缩小 5%，删除各页页首说明小字，界面更干净；商店所有交互键同样享受统一按键反馈。

## 修复

- 修复宠物详情面板背景描边从未渲染的问题（空裁剪路径吞掉画笔）。
- 修复商店按键悬浮时可能整键消失的问题（paint 期内抓帧不可靠，改为事件循环内缓存皮肤帧）。
- 修复装修面板按键没有悬浮反馈的问题。
- 修复简介/套装分栏素材文件名互换的历史遗留（命名归位）。
