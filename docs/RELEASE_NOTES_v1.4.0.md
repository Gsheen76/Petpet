# Pet陪它 v1.4.0

本次更新为 Petpet 加入完整的家园体验：小狗拥有独立的小屋活动模型，可以在
2.5D 地面上按目标移动、待机、说话和走到地毯睡觉；家具商店与装修编辑器也
已经接入原有 Pet 币和存档系统。快捷菜单同步重组，让常用入口更直接。

## 主要更新

- 快捷菜单改为“聊天、小屋、商店、互动、更多”一行五个入口。
- 互动页集中提供抚摸、喂食、玩耍和睡觉；更多页保留记录、成就、小游戏、
  设置、隐藏、教程、返回和退出。
- 新增固定在屏幕右下区域的家场景，主画布为 `900×768`。
- 家具装修侧栏独立位于画布左侧，使用双列卡片，不会遮挡房间内容。
- 家具支持购买、放置、拖动、缩放、旋转、收纳和变换存档；家具图片保持
  原始比例，不会拉伸。
- 小屋内支持左键指定地面目的地，小狗会按前后左右四个方向在 2.5D 地面移动。
- 导航路线改为固定宠物脚印；小狗走过的脚印逐步消失，终点使用暖色倾斜
  椭圆和箭头提示。
- 小屋小狗新增正坐待机素材和暖色对话框；在小屋内右键小狗可使用与桌面相同
  的快捷交互。
- 手动睡觉或精力不足时，小狗会先走到已放置的地毯，再进入睡眠状态。
- 小屋睡眠使用独立 8 帧动画，以 `3 FPS` 缓慢循环；宠物在不同地面纵深保持
  一致大小，并使用素材自带接触阴影。
- 动画或导航素材缺失时保留安全占位回退，避免影响状态机和基础交互。

## 下载

- Windows 可执行文件：`Petpet.exe`
- Windows 便携包：`Petpet-v1.4.0-windows.zip`
- Apple 芯片 Mac：`Petpet-v1.4.0-macOS-arm64.zip`
- Intel Mac：`Petpet-v1.4.0-macOS-intel.zip`

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时可能需要在
“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级与数据

旧存档会自动补齐家场景视口、装修状态、已购家具、家具位置/缩放/旋转和小屋
宠物位置等字段。升级不会重置宠物名字、等级、经验、好感、Pet 币、装扮、
强化、小游戏记录、设置、API Key 或聊天记忆。

Windows 自动更新继续原位替换 `Petpet.exe`，用户数据保存在
`%LOCALAPPDATA%\Petpet`；macOS 用户数据保存在
`~/Library/Application Support/Petpet`。
