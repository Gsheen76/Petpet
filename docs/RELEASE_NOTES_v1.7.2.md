# Pet陪它 v1.7.2

> 发布日期：2026-09-12　|　上一版本：v1.7.1　|　主打：长期记忆档案 + 全景装修 + 存档备份

## 更新亮点

- **聊天长期记忆档案**：TA 会自动从聊天里记住你——六栏结构化档案（称呼 / 作息 / 喜欢 / 讨厌 / 重要的事 / 其他），每栏有条数上限、单条限长，聊天中每几轮静默抽取一次。聊天窗标题行新增「档案」入口：随时查看、改正、删除 TA 记住的内容，保存立即生效——改名后气泡里马上换新称呼叫你。
- **主动搭话会叫你**：空闲提醒不再千篇一律，台词从档案生成——知道你的称呼、喜欢的事、作息习惯（「小明，久坐不好，起来活动一下吧～」），深夜引用你自己的作息提醒你睡；离开六个多小时再回来有专属想念台词。触发节奏不变：默认空闲半小时起、间隔三小时、凌晨不打扰、不消耗 AI 配额。
- **家园全景装修**：进入装修模式时窗口临时加宽，整间小屋一屏铺满，所有家具同屏可见、直接拖放，不再需要左右平移；装修分栏由七类合并为 全部 / 家具 / 装饰 / 玩具。
- **家具扩充与重制**：新增四件家具——奶油落地灯（140）、矮矮小书架（220）、圆润小茶几（180）、玩具小藤篮（120）；原有地毯 / 沙发 / 绿植 / 墙画四件按新风格统一重制。
- **小屋恢复置顶**：小屋窗口重新保持最前，不被其他窗口挡住。

## 实用功能

- **存档一键备份与恢复**：设置页新增「💾 存档备份」——「一键备份」存到本地 backups/ 目录（自动保留最近 5 份），「导出副本…」另存到任意位置，「从备份恢复…」选择备份包还原（恢复前自动做一次安全快照防手滑，完成后程序自动重启）；包含进度、聊天记忆、设置与头像，**不包含 API Key**，且还原只接受白名单文件。
- **开机自动启动**：设置页「界面体验」新增开关，开机后自动把 TA 叫到桌面上（仅 Windows，写当前用户注册表 Run 键）。
- **聊天停止与重新生成**：流式回复期间「发送」键变「停止」，点按立即截断、已收到的部分保留为该条回复；「↻」键把上一条回复丢掉重新生成（不重复计入互动次数）。
- **礼物空背包直达**：宠物面板礼物页背包为空时，一键直达商店礼物页。
- **提醒专属音效**：喝水（水滴）、护眼（低铃）、起身活动（上行双音）各有提示音，可在设置关闭。
- **macOS 游戏自动隐藏**：Mac 端检测前台应用路径，进入游戏自动藏起、退出自动回来，与 Windows 同一套开关。

## 界面与手感

- **按键反馈全应用统一**：聊天窗（发送 / 上传 / 模式切换 / 工具排 / API Key 弹窗）、设置页、新手引导等全部按键接入统一手感——悬浮放大 + 白洗，按住内缩压暗，键内松开回弹后触发。
- **滚动条全应用统一**为商店同款（透明槽 + 珊瑚棕圆角手柄），聊天与设置页跟进。
- 档案保存后宠物气泡回应；改称呼会复述新称呼。

## 修复与工程

- 修复按住显示 API Key 松开后不恢复密文的潜在问题（按键延迟触发机制的边界）。
- 修复依赖清单缺失 Pillow / numpy 导致全新环境启动失败的问题；CI 改为直接按 `requirements/runtime.txt` 安装，契约文件重新被验证。
- GitHub Actions 全量测试（795 项）每次 push 自动回归；单文件打包 + 资源内嵌经重建验证。
