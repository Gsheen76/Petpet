# Pet陪它 v1.2.1

这是一次以“初次相遇、个性命名和界面稳定性”为核心的体验更新。

## 主要更新

- 新增五步治愈系新手教程，依次介绍抚摸、拖动、聊天、右键互动和托盘操作。
- 教程结束时可以为小狗命名，名字会保存在本地。
- 自定义名字会同步显示在聊天窗口、AI 人设、状态卡、完整状态页和托盘提示中。
- 可以从“右键 → 更多 → 教程”重新查看教程或修改名字。
- 将“更多”改为独立功能画布，提供设置、隐藏、教程、返回和退出，并固定返回与退出的末尾顺序。
- 放大教程页面、正文、标题、命名输入框和操作按钮，改善高分辨率屏幕下的可读性。
- 放大设置页面与托盘菜单，优化状态卡文案和布局。
- 对进食动画进行轻微色彩校正，使动作前后颜色更一致。
- 修复连续快速互动时，单行说话框右侧偶尔绘制不完整的问题。
- 正式打包版本不再显示仅供本地开发使用的调试入口。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.2.1-windows.zip`。
- Apple 芯片 Mac（M1/M2/M3/M4 等）：下载 `Petpet-v1.2.1-macOS-arm64.zip`。
- Intel Mac：下载 `Petpet-v1.2.1-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时，可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级说明

本次升级会保留原有配置、聊天记忆、养成状态和设置。已有用户首次运行 v1.2.1 时会看到一次新手教程，完成后即可保存小狗名字。
