# Pet陪它 v1.3.1

本次更新重点优化待机装扮体验，并补全可长期循环的随机挖宝玩法。装饰不再依赖
每种动作与商品的组合图片，玩家可以自由搭配、试戴和微调，同时保持动作期间的
画面稳定。

## 主要更新

- 装扮系统改为待机姿势独立贴图，可同时组合帽子、眼镜和颈饰；其他动作暂不
  叠加装饰，避免错位、尾巴残影和组合数量膨胀。
- 商店新增分类页和购买前试戴。试戴使用独立状态，不会改变真实装备或购买记录。
- 新增奶油贝雷帽、暖金圆框眼镜、酷黑爪印墨镜、晴空爪印领结和噜噜小橘子帽，
  并重新平衡商品售价。
- 装饰微调支持直接拖动位置、调整大小与旋转角度、恢复默认；选中框改为高对比
  黄色，并移除冗余方向按钮。
- 新增“持久活力”强化，共 5 级，最高减缓 50% 的清醒饱腹、心情和精力自然
  消耗，不影响睡眠时的饱腹消耗。
- 新增随机挖宝事件：每分钟进行低概率检查，发现后有 20 分钟冷却；奖励按四档
  概率在 5 至 100 Pet币间随机，未领取奖励会随存档保留。
- 点击“发现宝藏”后播放 30 帧、20 FPS 专属动画，小狗会以金色星星眼捧着
  Pet币展示；动画完整结束后奖励才会入账，并防止重复领取。
- 玩耍动画提升至 24 FPS，动作期间不再叠加待机装饰，移除不自然的尾巴残影。
- 重写说话气泡排队和换行逻辑，修复交互时主动说话覆盖、长句右侧或底部显示
  不完整的问题。
- 低心情与饥饿状态继续显示待机装扮模型，通过附近的“陪我玩”“喂喂我”短气泡
  表达需求，不再切回旧模型。

## 下载

- Windows：下载 `Petpet.exe` 或 `Petpet-v1.3.1-windows.zip`。
- Apple 芯片 Mac：等待对应构建产物 `Petpet-v1.3.1-macOS-arm64.zip`。
- Intel Mac：等待对应构建产物 `Petpet-v1.3.1-macOS-intel.zip`。

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。

## 升级与数据

旧存档会自动补齐装饰微调、持久活力、挖宝冷却和待领取奖励字段，不会重置名字、
等级、经验、好感、Pet币、设置、API Key 或聊天记忆。Windows 自动更新继续原位
替换 `Petpet.exe`，用户数据稳定保存在 `%LOCALAPPDATA%\Petpet`。
