# Pet陪它 v1.4.1

本次更新集中改善聊天、设置和新手引导。玩家不配置 API Key 也可以使用默认免费
文字聊天；需要图片理解时，可切换到个人 GLM-4.6V-Flash 并上传图片。小狗同时
接入随版本维护的玩法知识库，可以在聊天中介绍 Pet陪它的功能。

## 主要更新

- 聊天模式精简为“免费聊天”和“自己配置”，切换区域使用统一尺寸和淡粉色选中态。
- 默认免费文字聊天通过 Petpet 代理提供，并按安装实例限制额度；不可用时会提示
  稍后重试或配置个人 API Key。
- 个人聊天保留 GLM-4.6V-Flash，支持文字和图片消息；玩家 API Key 只保存在本机。
- 小狗可回答家园、家具、快捷菜单、互动、成长、小游戏、设置和数据保存等游戏问题。
- 清理模型输出中的动作括号和多余狗狗图标，让回复更像自然对话。
- 聊天窗口、气泡、输入栏、模式选择、确认卡片和头像菜单统一为暖色圆角风格。
- 聊天双方增加头像框；玩家可在右上角选择或恢复默认头像。
- 设置页和教程默认在屏幕中央打开，字体、控件高度和排版层级重新统一。
- 健康提醒使用“少 / 适中 / 多”三档，性格偏好使用“文静 / 适中 / 活泼”三档。
- 新手教程精简为六页，覆盖桌面陪伴、小屋移动、图片聊天、健康提醒和命名。
- 旧的提醒与陪伴数值会自动映射到最接近的档位，不重置其他本地设置。

## 下载

- Windows 可执行文件：`Petpet.exe`
- Windows 便携包：`Petpet-v1.4.1-windows.zip`
- Apple 芯片 Mac：`Petpet-v1.4.1-macOS-arm64.zip`
- Intel Mac：`Petpet-v1.4.1-macOS-intel.zip`

macOS 应用当前尚未进行 Apple Developer ID 签名和公证。首次打开时可能需要在
“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 升级与数据

升级不会重置宠物名字、成长状态、Pet 币、家具、装扮、设置、玩家头像、个人
API Key 或聊天记忆。Windows 用户数据继续保存在 `%LOCALAPPDATA%\Petpet`，macOS
用户数据保存在 `~/Library/Application Support/Petpet`。
