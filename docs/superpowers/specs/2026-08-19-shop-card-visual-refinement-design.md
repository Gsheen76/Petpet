# 商店卡片视觉与宠物折扣修订设计

**日期：** 2026-08-19
**状态：** 已确认

## 目标

统一宠物、套装和家具页面的卡片边界，保留且突出宠物栏首次购买 76 折，同时撤回套装和家具栏的首次购买折扣。优化套装宠物选择器，并将冰淇淋的空套装页面改为与现有“更多套装正在准备”相同的占位卡。

## 折扣规则

- 仅宠物栏目拥有首次购买 76 折权益。
- 冰淇淋在宠物折扣可用时显示原价 `1000 Pet币`、折后价 `760 Pet币` 和 `-24%`。
- 宠物购买成功后消费宠物栏目权益；失败或重复购买不消费。
- 套装和家具按商品定义中的原价展示和结算，不再读取或消费首次购买折扣。
- 旧存档中已有的 `outfits`、`home` 折扣标记不迁移、不删除，只在运行时忽略，避免不必要的存档改写。

## 宠物卡片

- 午餐肉和冰淇淋分别放在独立的浅色卡片中。
- 卡片复用套装卡的白色背景、暖色细边框和圆角，不新增另一套视觉语言。
- 昵称规则保持不变：未改名只显示默认名；改名后显示“玩家昵称（默认名）”。
- 冰淇淋价格行只显示删除线原价与折后价。
- `-24%` 使用比正文更小、加粗的独立气泡徽章，固定在卡片右上区域。
- 冰淇淋右侧操作区从上到下显示折扣徽章、拥有状态和购买按钮，避免与价格文字挤在同一行。
- 无折扣的宠物不显示折扣徽章。

## 套装宠物选择器

- 午餐肉和冰淇淋按钮放入一个带暖色细边框和圆角的外层容器，结构与商店大栏目一致。
- 选中按钮使用珊瑚色背景和白色文字。
- 未选中按钮使用透明浅色背景和棕色文字；悬停时显示浅桃色反馈。
- 按钮尺寸稳定，切换状态不改变布局宽高。

## 冰淇淋空状态

- 冰淇淋没有套装时不再只显示居中的单行文字。
- 显示与“更多套装正在准备”相同的完整占位卡。
- 标题为“冰淇淋套装正在准备”。
- 说明保留“后续会继续补充新的完整套装，已购买的套装可以随时切换。”
- 不创建虚假的冰淇淋套装商品。

## 实现边界

- 复用现有 `decorationCard`、`placeholderCard`、大栏目和分类按钮的 QSS 颜色与边框。
- 宠物卡保留稳定的动态对象名，供现有边界测试定位。
- 仅修改成长经济和商店 UI 相关代码与测试，不重构通用商品卡组件。
- 不改版本号、发布元数据、宠物资源或套装资源。

## 验证

- 经济测试验证宠物仍为 1000 → 760，套装 680、760 原价结算，家具 240 等原价结算。
- UI 边界测试验证宠物卡外框、删除线价格、独立折扣徽章及其小号字体。
- UI 边界测试验证选择器外框、按钮 checked 状态和不同状态样式入口。
- UI 边界测试验证冰淇淋页面显示完整占位卡及指定标题、说明。
- 运行 progression 聚焦测试、Task 7 相关边界测试、全量测试、`compileall` 和 `git diff --check`。
