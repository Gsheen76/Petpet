# 小屋状态卡与商店双列设计

## 目标

- 新增免费家居“状态卡”，领取后可作为墙饰放置、收纳、移动、缩放和旋转。
- 卡面实时显示等级、好感、饱腹、心情与精力，替代小屋右上角“属性”按钮。
- 商店强化页改为每行两张紧凑卡片，减少重复说明。

## 实现边界

- 状态卡继续使用现有 `owned_home_decorations`、位置和变换存档，不新增平行存档结构。
- 家具目录提供免费价格、墙面默认位置和固定画布尺寸；卡面由 Qt 实时绘制，商店与小屋共用同一绘制函数。
- 小屋顶栏顺序固定为“商店、互动、装修、退出”。
- 强化卡只保留名称、等级、当前效果和购买按钮，两列尺寸一致。

## 验证

- 免费领取不扣 Pet币，且可正常收纳、放置和保存变换。
- 属性变化后状态卡图像随之变化。
- 小屋顶栏不存在属性入口。
- 强化页六项以三行两列呈现，卡片不含冗长的升级前后双段说明。
