# Petpet 暖色聊天组件设计

## 范围

本轮完整改造聊天窗口内的模式切换、清除确认、头像选项、API 配置和模型选择。文件选择器继续使用系统原生窗口。组件样式沉淀为可复用入口，但不在本轮批量替换其他游戏窗口。

## 视觉语言

- 主色：柔和桃粉 `#F3B8AD`，选中底色使用低饱和淡粉 `#F8DCD7`。
- 辅色：奶油黄 `#FFF1CC`、杏色 `#F7D7B5`、鼠尾草绿 `#C9D8BE`。
- 基底：暖白 `#FFF9F4`、奶油白 `#FFFDF9`。
- 文字：暖棕 `#704B3C`，次级文字 `#A47B6B`。
- 所有卡片、输入框、菜单项、按钮均使用圆角；不显示蓝色焦点框或系统蓝色选中态。

## 分段选择器

- `免费` 与 `自定义` 使用完全相同的固定宽度、高度、内边距和字体粗细。
- 选中态只改变背景、边框与文字颜色，不改变字号、粗细或尺寸策略。
- 选中态为淡粉色，未选中态为透明暖白。
- 模式切换前后外框位置、整体高度与两个按钮基线保持不变。

## 暖色确认浮层

- 清除记忆不再使用系统 `QMessageBox`。
- 使用无边框、圆角、置顶的 Petpet 对话框，包含柔和问号徽章、短标题、说明和两个胶囊按钮。
- 主操作 `重新相识` 使用淡粉色；保留操作 `继续陪着我` 使用暖白边框，并作为默认焦点。
- 弹窗不显示系统标题栏、系统问号图标或蓝色边框。

## 头像选项

- 不再使用系统 `QMenu`。
- 点击右上角 `头像` 后，在按钮下方显示圆角暖白小卡片。
- 两项为 `选择头像`、`恢复默认`，每项固定高度，悬停使用淡粉色。
- 点击外部或完成选择后自动关闭。

## API 配置

- 现有配置对话框改为无系统标题栏、透明顶层与圆角内容卡片。
- 标题精简为 `自定义聊天`，移除钥匙 emoji 与系统帮助按钮。
- 状态、隐私说明压缩为短句并用奶油黄提示卡承载。
- 输入框、按钮、模型框保持统一 14–18px 圆角。
- 保存成功在对话框内显示短状态并关闭，不再弹系统成功框。
- 错误优先在弹窗内显示；仅不可恢复的外部错误使用统一暖色提示组件。

## 模型选择

- 当前只有一个个人模型时，显示静态圆角模型卡 `GLM-4.6V-Flash`，不展示重复下拉项。
- 数据结构继续允许以后多个模型；达到两个及以上时才显示自绘/完整 QSS 的下拉列表。
- 多模型列表使用暖白背景、圆角边框、淡粉选中态和暖棕文字，禁用系统蓝色高亮。

## 可复用边界

- 提取聊天用的暖色调色常量与 `PetpetConfirmDialog`、`PetpetPopupMenu`。
- 组件只暴露结果或选择信号，不耦合聊天业务。
- 后续其他界面可逐步采用，不要求本轮全局替换。

## 测试

- 分段按钮切换前后几何完全一致，选中态包含淡粉色且不改变 font weight。
- 清除记忆不调用 `QMessageBox`，通过自绘对话框结果控制清除。
- 头像入口不创建 `QMenu`，选项卡包含两个固定项。
- 单模型时不显示 `QComboBox`；API 对话框无系统标题栏且有圆角卡片。
- 运行聊天 focused tests、完整 `pytest -q`，截图检查所有状态。
