# Petpet 圆角精简聊天界面设计

## 范围

本轮只重构聊天窗口的视觉与模式选择，不修改聊天服务、额度、模型请求和历史存储逻辑。全游戏界面默认采用圆角风格，作为后续新增或修改界面的长期规范；本轮不批量改动其他已完成窗口。

## 已确认方向

采用 B「分段切换」：聊天窗口底部常驻 `免费｜自定义` 两段式选择器。当前模式使用浅色实心胶囊突出，另一模式保持低对比文字。

### 免费模式

- 底部只显示模式选择器与清除记忆图标。
- 不显示 API、模型名称、图片上传或配置说明。
- 免费服务异常时只显示一行短提示：`免费聊天暂不可用，请稍后再试。`
- 免费额度用完时显示：`今日免费次数已用完，可切换自定义。`

### 自定义模式

- 切换到自定义后才显示模型、上传图片、API 设置和清除记忆。
- 未配置可用 Key 时，选择 `自定义` 直接打开配置窗口；取消后仍保留原模式。
- 模型入口仅显示短名称 `GLM-4.6V`；完整名称放入工具提示和配置窗口。
- 上传图片保持仅对支持图片的模型可见。

## 视觉规范

- 主窗口圆角：24px。
- 标题栏和底部编辑区圆角：18px。
- 消息气泡圆角：18px，气泡尾侧使用 7px 小圆角。
- 输入框与发送按钮圆角：15px。
- 分段选择器使用全圆角胶囊；上传、设置、清除使用等尺寸圆形按钮。
- 延续家园的暖米白、浅桃色和暖棕文字，不使用蓝色高亮。
- 标题仅显示宠物名；按钮正文不再放装饰性 emoji，图标按钮提供工具提示。
- 消息区扩大留白，减少边框和同时出现的文字层级。

## 交互与状态

- 点击 `免费`：直接保存并切换到默认代理。
- 点击 `自定义`：已有可用 Key 时直接切换；没有 Key 时打开配置窗口，保存成功后切换。
- 点击模型短名称或设置图标：打开同一个自定义配置窗口。
- 点击上传图标：沿用现有选图和预览逻辑。
- 点击清除图标：沿用现有清除记忆逻辑，并保留确认步骤。
- 发送中禁用模式切换和发送按钮，结束后恢复，避免中途更换请求来源。

## 代码结构

- 在 `ChatWindow` 中用一个分段选择组件替代当前弹出菜单式模式按钮。
- 模式组件对外只发出 `default` / `personal` 两种选择，现有配置层继续使用原值。
- 将底部工具栏刷新集中到一个方法，根据当前模式、模型能力、Key 状态和发送状态控制可见性与启用状态。
- 继续复用现有聊天气泡、配置弹窗、图片预览和错误映射，不改网络协议。

## 测试与验收

- 先补失败测试，覆盖两个分段按钮、当前态样式和模式切换。
- 覆盖免费态隐藏高级工具、自定义态按模型能力显示工具。
- 覆盖无 Key 选择自定义时打开配置、取消不切换、保存后切换。
- 覆盖精简后的状态提示文本，不向玩家展示技术异常名。
- 运行聊天 focused tests，再运行 `pytest -q`。
- 启动当前 worktree 的 `pet.py`，实际截图检查圆角、间距、窄窗口下的底部布局。
