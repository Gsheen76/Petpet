# 家园右下角上拉操作菜单设计

## 目标

将家园顶部右侧的“商店、互动、装修、退出”横排按钮收纳到右下角，减少场景顶部遮挡，并统一按钮视觉。

## 交互

- 右下角常驻一个“菜单⌃”主按钮。
- 点击主按钮后，主操作从按钮上方向上展开；从近到远依次为商店、互动、装修、退出。
- 退出放在离主按钮最远的位置，降低误触风险。
- 点击“互动”后，主操作列表原位切换为抚摸、喂食、玩耍、睡觉；主按钮显示“返回⌄”。
- 子菜单点击“返回⌄”回到主操作列表；任一菜单打开时点击场景空白会关闭菜单并消费本次点击，避免小狗被意外移动。
- 商店、互动、装修和退出继续调用原有功能，不改变存档和业务逻辑。

## 视觉

- 主按钮使用珊瑚色纵向渐变、浅色描边、柔和下投影和加粗文字。
- 展开项使用奶油色半透明渐变、暖棕文字与统一圆角。
- 主按钮和展开项统一为 92 像素宽；主按钮高 44 像素，展开项高 40 像素，间距 7 像素。
- 整组控件距 600×768 家园画布右侧和底部均为 14 像素。

## 验证

- 几何测试验证按钮位于画布右下角、选项向上排列且退出最远。
- 点击测试验证主菜单、互动子菜单、返回和点击空白关闭。
- 家园专项测试通过后再运行全量测试和源码启动冒烟。
