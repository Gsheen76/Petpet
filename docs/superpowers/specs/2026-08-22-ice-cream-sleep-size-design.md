# 冰淇淋睡眠体型与待机一致性设计

## 目标

让冰淇淋在桌面和家园进入睡眠时，比原始尺寸略大但不追求与待机同高；保留睡眠横躺素材的宽高比、底部锚定和动画帧，不改变窗口大小或其他宠物动作。

## 根因

- 前一轮把桌面比例直接调到 `1.34`、家园调到 `1.0`，虽然达到待机同高，但实际视觉反馈显示睡眠体型过大。

## 方案

- 桌面 `assets/runtime/pets/ice_cream/desktop/animations/manifest.json` 将睡眠 `scale` 调整为 `0.75`，相对原始 `0.62` 温和增大。
- 家园 `petpet/home/rendering.py` 将冰淇淋的 `HOME_PET_SLEEP_VISUAL_SCALE` 调整为 `0.60`，相对原始 `0.50` 温和增大。
- 不改 `anchor_bottom`、脚底阴影逻辑、素材裁剪区和睡眠 FPS；睡眠横向宽度仍由素材宽高比决定。

## 验证

- 回归测试检查冰淇淋桌面 manifest 比例为 `0.75`，并验证其介于原始睡眠与待机高度之间。
- 家园测试检查冰淇淋睡眠矩形为待机基准高度的 `0.60`。
- 运行家园/动画焦点测试与全量 pytest；最后重启源码小狗做人工验证。
