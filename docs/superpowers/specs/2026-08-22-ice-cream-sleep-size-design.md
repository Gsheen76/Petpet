# 冰淇淋睡眠体型与待机一致性设计

## 目标

让冰淇淋在桌面和家园进入睡眠时，主体可见高度与待机状态一致；保留睡眠横躺素材的宽高比、底部锚定和动画帧，不改变窗口大小或其他宠物动作。

## 根因

- 桌面冰淇淋睡眠精灵复用家园横向睡眠图，manifest 的 `scale: 0.62` 使可见高度约为待机的一半。
- 家园渲染通过 `HOME_PET_SLEEP_VISUAL_SCALE = 0.50` 显式缩小睡眠绘制矩形，同样造成高度偏小。

## 方案

- 桌面 `assets/runtime/pets/ice_cream/desktop/animations/manifest.json` 将睡眠 `scale` 调整为 `1.34`。该值由 190×160 桌面绘制区、待机帧 460px 可见高度和睡眠裁剪帧 268px 可见高度计算得出，四舍五入后使两者显示高度一致。
- 家园 `petpet/home/rendering.py` 将 `HOME_PET_SLEEP_VISUAL_SCALE` 调整为 `1.0`。家园绘制矩形本身以待机基准高度计算，因此该值让睡眠矩形高度与待机相同。
- 不改 `anchor_bottom`、脚底阴影逻辑、素材裁剪区和睡眠 FPS；睡眠横向宽度仍由素材宽高比决定。

## 验证

- 回归测试检查冰淇淋桌面 manifest 比例为 `1.34`。
- 家园测试检查睡眠渲染高度与待机渲染高度相等。
- 运行家园/动画焦点测试与全量 pytest；最后重启源码小狗做人工验证。
