# 家园宠物待机、固定尺寸与图片导航设计

日期：2026-08-10
状态：用户已确认

## 目标

升级家园宠物的静止状态、睡眠流程和移动导航反馈：宠物在没有指令时显示高质量正坐待机图；家园内所有宠物状态保持当前最前方对应的视觉大小；手动睡眠先走到地毯；移动路线和终点全部改用高质量透明图片素材。

## 范围

本轮包含：

- 单张正坐待机素材及其渲染状态。
- 固定家园宠物显示尺寸。
- 家园手动睡眠的走向地毯流程。
- 图片脚印路线、图片目的地椭圆和图片箭头。
- 对应的几何、状态、生命周期和渲染测试。

本轮不包含：

- 待机循环动画。
- 正式睡眠模型或睡眠动画。
- 家具碰撞、绕行或 A* 寻路。
- 修改现有四方向行走素材的动作内容。

## 图片素材

新增以下透明 PNG：

### `home-pet-idle-sit.png`

- 高质量正坐小狗，正面略偏右视角。
- 以现有 `home-pet-walk-down.png` 和 `home-pet-walk-back-right.png` 为角色身份、毛色、脸型、眼睛、耳朵、身体比例和手绘质感参考。
- 奶油金毛色、大眼睛、蓬松垂耳、柔和治愈的绘本质感。
- 四肢完整，前爪自然并拢，身体坐正，尾巴可在身体一侧露出。
- 不含地板、投影、文字、水印或额外物体；阴影继续由程序统一绘制。
- 脚底锚点清晰，四周留有安全透明边距。

### `home-nav-paw.png`

- 单枚高质量小狗脚印，不制作整条固定路线。
- 主肉垫与四枚趾垫圆润饱满，带轻微奶油色高光和焦糖粉渐变。
- 透明背景，无文字、无水印、无外部投影。
- 程序沿路线重复排列，并通过交替镜像、轻微横向偏移和沿路线旋转形成左右脚步。

### `home-nav-target.png`

- 2.5D 倾斜地面的扁椭圆终点标记，宽高比约为 `2.1:1`。
- 奶油色半透明内层、蜜桃粉外圈、柔和暖色光晕，并带小爪印装饰。
- 透明背景，不含箭头，便于箭头独立浮动。

### `home-nav-arrow.png`

- 圆润软糖风的向下箭头，焦糖粉与珊瑚蜜桃色渐变。
- 顶部带一个克制的小爱心或蝴蝶结装饰。
- 透明背景，无文字、无水印。
- 程序让箭头在终点上方做轻微上下浮动和呼吸缩放。

所有素材以高于实际显示尺寸的分辨率生成，再由 Qt 等比平滑缩小。不得拉伸变形。

## 宠物状态与渲染

### 待机

- `HomePetController.state == "idle"` 时显示 `home-pet-idle-sit.png`。
- 待机图不继承最后一次移动方向，不镜像，始终使用正面略偏右姿势。
- 待机为单张静态图，不播放眨眼、呼吸或耳朵动画。

### 行走

- `manual_walk`、`manual_sleep_walk` 和 `auto_sleep_walk` 继续使用现有四方向八帧素材。
- 移动方向和脚底逐帧校准保持现有逻辑。

### 睡眠

- 到达睡眠点后进入 `sleeping`。
- 本轮继续使用现有临时睡眠占位表现，后续可在不改变状态机的前提下替换正式素材。

## 固定显示尺寸

- 移除家园宠物随世界坐标 `y` 变化的远小近大缩放。
- 宠物的基础显示尺寸固定为当前前景最大深度缩放 `1.08` 对应的大小。
- 无论位于可行走区域顶部、中心或底部，脚底到头顶的目标视觉高度保持一致。
- 前向、背向和待机素材允许各自拥有一次性的内部脚底与内容边界校准，用于消除原始素材留白差异；该校准不能依赖宠物位置，也不能重新引入远近缩放。
- 宠物命中矩形、全局界面锚点、阴影和家具深度排序继续以固定大小的脚底锚点为基准。

## 手动与自动睡眠

### 快捷菜单手动睡眠

- 家园激活且宠物醒着时，快捷菜单“睡觉”不立即设置共享 `sleeping=True`。
- 家园场景接收手动睡眠请求，目标为当前已购买、已放置地毯的中心。
- 地毯不可用时使用 `HOME_DEFAULT_SLEEP_POINT`。
- 控制器进入 `manual_sleep_walk`，到达后进入 `sleeping`，共享状态设置为 `sleep_mode="manual"` 并记录一次手动睡眠。
- 手动睡眠不因精力自动恢复而醒来。
- 宠物已经睡着时再次点击“睡觉”则立即原地醒来，并保留当前家园位置。
- 手动睡眠路线属于用户指令，因此显示图片脚印路线和图片终点反馈。

### 低精力自动睡眠

- 现有低精力逻辑继续进入 `auto_sleep_walk`，目标同样优先使用地毯中心，否则使用默认睡眠点。
- 到达后设置 `sleep_mode="auto"`，精力恢复到阈值后允许自动醒来。
- 自动睡眠不显示路线和终点素材，避免无操作时出现干扰性 UI。

### 用户打断

- 左键新目的地可以打断 `manual_sleep_walk`、`auto_sleep_walk` 或 `sleeping`。
- 打断后清理睡眠状态并进入现有手动移动冷却逻辑。
- 装修、隐藏或退出家园时取消临时目标并清理导航反馈，但保留最后位置。

## 图片导航反馈

### 脚印路线

- 起点为宠物当前脚底位置，终点为手动目标。
- 按固定屏幕间距沿直线采样，不绘制虚线。
- 脚印沿路径方向旋转，左右交替镜像并产生少量横向偏移。
- 路线随宠物前进缩短，已经走过的脚印不再显示。
- 距离过短时可以隐藏脚印，只保留终点标记。

### 目的地

- `home-nav-target.png` 按倾斜椭圆比例等比绘制在地面层。
- 标记尺寸固定，不再使用终点 `y` 对应的深度缩放。
- `home-nav-arrow.png` 独立放在椭圆上方，进行小幅上下浮动和约 `±4%` 的呼吸缩放。
- 终点整体轻微呼吸，但不得剧烈跳动或遮挡宠物。

### 生命周期与层级

- 左键新目标替换旧目标和旧路线。
- 手动睡眠请求创建指向地毯或默认睡眠点的导航反馈。
- 抵达后脚印、椭圆和箭头在 `350ms` 内一起淡出。
- 装修、隐藏或退出家园立即清理反馈。
- 导航反馈位于地毯上方、宠物与实体家具下方，保持现有遮挡顺序。

## 降级策略

- 待机素材加载失败时，回退为现有前向行走素材第 0 帧，不显示空白宠物。
- 任一导航素材加载失败时，仅跳过对应图片，不阻止移动和睡眠状态转换。
- 所有素材尺寸计算必须防御空图和无效尺寸。

## 测试

在实现前先添加失败测试，至少覆盖：

- 待机状态选择独立坐姿素材。
- 待机素材缺失时回退前向第 0 帧。
- 家园顶部与底部的宠物绘制矩形尺寸相同，脚底仍锚定到位置。
- 前向、背向和待机的显示尺寸不依赖世界纵坐标。
- 快捷菜单睡觉在家园中进入 `manual_sleep_walk`，不会立即睡眠。
- 手动睡眠优先走向已放置地毯，缺少地毯时使用默认点。
- 到达后记录手动睡眠，且精力恢复不会自动唤醒。
- 已睡眠时快捷菜单操作可以原地唤醒。
- 自动睡眠仍可自动唤醒且不创建导航反馈。
- 脚印采样数量随剩余距离缩短，方向旋转和左右交替稳定。
- 目的地标记使用固定扁椭圆几何，箭头拥有独立浮动偏移。
- 抵达、替换目标、装修、隐藏和退出会正确淡出或清理反馈。
- focused tests、完整 `pytest -q`、`py_compile` 和 `git diff --check`。

## 手工验收

1. 进入家园后不操作，确认小狗正坐待机且没有动画。
2. 分别点击地面顶部和底部，确认移动前后小狗大小不变。
3. 检查路线是否由清晰、交替且朝向正确的脚印组成。
4. 检查终点是否为贴合地面的倾斜椭圆，箭头可爱且不过度跳动。
5. 从快捷菜单点击“睡觉”，确认小狗先走到地毯再睡。
6. 收纳地毯后再次睡觉，确认走到默认睡眠点。
7. 检查自动低精力睡眠不显示导航反馈，并可在恢复后自动醒来。
