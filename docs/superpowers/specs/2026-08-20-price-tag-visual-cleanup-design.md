# 商店价格标签视觉修复设计

**日期**：2026-08-20
**状态**：待评审

## 问题

现有价格底图的透明边缘不干净，蝴蝶结与卷轴纹样侵入文字安全区；在窄卡片中，底图缩放后会裁掉装饰并遮挡“售价”“免费赠送”等动态文字。

## 方案

价格标签改为一个统一的原生控件，而非承载内容的插画贴图：

- 使用不含文字的圆角奶油底、细金色描边和左侧小爪币图标；文字始终由 `QLabel` 绘制，保留足够的左右内边距。
- 标签依据内容自适应宽度，并有固定最小高度；不会通过缩放或裁切改变文字与装饰的关系。
- 免费显示“免费赠送”；常规显示“售价：X Pet币”；折扣项按“原价：X Pet币”（删除线）、“现价：Y Pet币”、`-Z%` 三个独立文本块排版。
- 宠物、套装、家具复用同一组件与同一排版规则；不改动购买逻辑、折扣算法、卡片尺寸或家具展示图的等比缩放。

## 验证

- UI 边界测试验证价格标签不依赖 `border-image`，并保留免费、常规与折扣文本/删除线语义。
- 焦点 UI 测试及完整 `python -m pytest -q` 通过。
- 人工检查在宠物、套装、家具三种窄宽度卡片中，文字不被装饰遮挡且没有裁切。
