# 家园宠物点击与统一界面锚点设计

日期：2026-08-10

## 目标

家园小狗应当像屋外桌面小狗一样承载说话、快捷菜单和功能窗口，同时保留家园内的 2.5D 移动交互：

- 左键点击有效地面，下达移动目标。
- 右键仅在点中家园小狗时，打开屋外同款快捷菜单。
- 家园中的说话气泡、快捷菜单、状态卡和功能窗口均以家园小狗为位置参考。
- 屋内外共用现有功能实现，不复制第二套菜单或气泡系统。

## 非目标

- 不改变快捷菜单的按钮内容、分页或动作业务逻辑。
- 不增加左键拖动家园小狗。
- 不让右键空白地面继续承担移动功能。
- 不增加家具碰撞、绕行或寻路。
- 不改动正式动画素材。

## 输入路由

### 普通家园状态

1. 左键先检查家园按钮和控制区域，命中时执行原有控制逻辑。
2. 左键未命中控件且位于家园画布时，调用现有移动命令；目标仍由可走多边形约束，并显示路径和目的地反馈。
3. 右键计算家园小狗当前实际绘制矩形；只有命中该矩形时才打开快捷菜单。
4. 右键空白地面、墙面、家具或画布外均无操作。

### 装修状态

- 保持现有家具选择、拖动、缩放、旋转和按钮交互。
- 不接受宠物移动命令。
- 不打开宠物快捷菜单。

## 统一宠物界面锚点

`PetWindow` 提供统一的当前宠物界面上下文，而不是让浮层直接读取桌面宠物窗口的 `geometry()` 和可见状态。上下文至少包含：

- 当前宠物是否可用于显示浮层。
- 当前宠物在全局屏幕坐标中的矩形。
- 当前宠物所在屏幕的可用区域。

规则如下：

- 家园可见且未装修时，锚点为家园小狗当前绘制矩形转换成的全局屏幕矩形。
- 家园未显示时，锚点为桌面 `PetWindow` 的现有矩形。
- 家园装修、隐藏或关闭时，不把已隐藏的家园宠物作为有效锚点。

家园窗口负责提供家园小狗的全局矩形；`PetWindow` 负责在屋内外上下文之间选择。这样菜单和浮层无需依赖 `home_scene.py`，也不会复制业务动作。

## 快捷菜单与功能窗口

- 家园小狗右键命中后，仍创建现有 `BubbleMenu`。
- `BubbleMenu`、`StatBubble` 及其后续分页均使用统一锚点定位并跟随。
- “聊天、商店、记录、成就、小游戏、设置、教程”等现有窗口在显示时使用统一锚点附近的位置，而不是隐藏桌面小狗的旧坐标。
- 菜单动作仍调用原有 `PetWindow` 方法，状态、成长记录和存档逻辑保持单一来源。
- 在家园内再次执行“小屋”动作时，只关闭菜单并保持当前家园状态，不重置宠物位置、目标或自动睡眠运行时状态。

## 说话气泡

- `PetWindow.say(...)` 根据统一上下文判断是否可以说话，不再只检查桌面宠物窗口自身是否可见。
- `SpeechBubble` 使用统一锚点计算位置；家园宠物移动或相机变化时继续跟随。
- 自主说话、需求提醒、互动反馈、设置反馈和聊天回复全部继续通过同一个 `say(...)` 入口。
- 离开、隐藏家园或进入装修时清理不再有效的家园浮层；重新回到屋外后，后续气泡自动锚定桌面小狗。

## 生命周期与坐标

- 家园绘制矩形是窗口局部坐标；对外暴露前使用 `mapToGlobal` 转换。
- 浮层定位继续使用当前屏幕可用区域进行边缘约束。
- 家园每次同步移动后，若菜单或说话气泡可见，则让它们重新读取统一锚点并跟随。
- 新开菜单前关闭旧菜单，防止屋内外同时残留两套可见浮层。
- 目的地反馈仍只由手动左键移动创建；打开菜单不修改移动目标。

## 测试策略

遵循 RED-GREEN-REFACTOR：

1. 先修改现有右键移动测试，使左键移动成为期望行为，并确认旧实现失败。
2. 测试右键只有命中家园宠物绘制矩形才请求打开菜单；空白、家具、画布外和装修状态均不触发。
3. 测试家园宠物局部矩形正确转换为全局锚点。
4. 测试家园激活时 `say(...)` 不因桌面宠物隐藏而丢弃消息。
5. 测试 `BubbleMenu`、`StatBubble`、`SpeechBubble` 和代表性功能窗口使用统一锚点定位。
6. 测试家园内再次执行“小屋”不会重置家园控制器。
7. 运行 `tests/test_home_scene.py`、`tests/test_menu_ui.py` 等 focused tests，然后运行完整 `pytest -q`。

## 验收标准

- 左键点击地面时，小狗移动且路径反馈正常。
- 右键点小狗时出现与屋外一致的快捷菜单；右键其他区域无反应。
- 家园小狗移动时，菜单、状态卡和说话气泡保持跟随。
- 家园中能显示所有既有说话来源。
- 从菜单打开的窗口靠近家园画布和家园小狗，不跳到隐藏桌面宠物的旧位置。
- 进入装修或离开家园后没有残留浮层。
- 原有屋外菜单、说话、拖动和点击行为不回归。
