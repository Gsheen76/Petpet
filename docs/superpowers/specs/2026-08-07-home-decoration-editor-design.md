# 家场景装修编辑器设计

## 目标

把家场景装修改成直接操作的画布编辑器：非装修状态视野跟随小狗，装修状态才允许视野平移；底部弹出家具面板；家具选中后显示类似 PPT 图片的控制框，可拖动、缩放和旋转。

## 交互设计

- 家场景固定在屏幕右下角，保持圆角和当前 900 x 768 尺寸。
- 非装修状态隐藏左右视野按钮，并持续根据小狗世界坐标计算视野位置。
- 装修状态显示左右视野按钮，单击平移、按住连续平移；按钮只在此状态响应。
- 点击右下角“装修”进入装修状态，底部弹出装修抽屉；抽屉包含家具缩略图、中文名称、分类栏“全部/地毯/沙发/绿植/墙饰”和“放置/收纳”操作。
- 装修状态点击画布内家具即可选中；选中对象绘制高对比边框、四角/四边缩放手柄，以及顶部旋转手柄。
- 拖动家具主体修改世界坐标；拖动缩放手柄按对象中心等比修改 scale；拖动旋转手柄修改 rotation。所有值经过既有持久化边界规范化。
- 点击“退出”或右下角“退出装修”离开装修状态，关闭抽屉、清空选择、停止拖拽和平移；家具和视野变换保留，视野随后恢复跟随小狗。

## 架构

- `scene_system.py` 提供无 Qt 状态的编辑几何：控制框、手柄命中区域、等比缩放和角度计算。
- `home_scene.py` 负责 Qt 绘制、鼠标状态机、底部抽屉和按钮；继续调用 `progression.py` 保存位置与变换。
- 不新增存档字段；复用 `home_scene.decorating`、`viewport_x`、`home_decoration_positions`、`home_decoration_transforms` 和 `home_stored_decorations`。

## 边界与错误处理

- 缩放保持既有 `0.5..1.5`，旋转保持 `-180..180`，位置保持家具尺寸对应的世界边界。
- 已收纳家具不参与画布命中和绘制；退出装修后所有家具鼠标操作均无效。
- 面板外点击不改变选择；点击空白清除选择。
- 平移始终限制在 `0..900`，且装修关闭时不保存新的手动跟随状态。

## 测试验收

- 纯逻辑测试覆盖控制框/手柄几何、缩放比例、旋转角度和镜头模式切换。
- Qt 测试覆盖装修面板可见性、分类/图片/收纳操作、家具主体与手柄命中、退出后编辑禁用、非装修视野跟随。
- 执行 focused tests 后执行完整 `pytest -q`，再启动源码实例进行手工验收。
