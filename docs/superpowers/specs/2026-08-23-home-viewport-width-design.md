# 家园视口宽度缩减设计

## 目标

将家园场景的可见画布宽度减少三分之一，从 900 像素改为 600 像素；高度保持 768 像素。

## 设计

- 家园世界继续使用 1800×768 坐标，不缩放背景、家具、宠物或动画。
- 可见视口改为 600×768，背景按相机位置裁切显示。
- 普通模式下相机继续自动跟随宠物；装修模式继续允许左右平移。
- 最大相机横坐标由 900 增加到 1200，以保证缩窄后仍可查看世界最右侧。
- 装修侧栏保持 338 像素并位于画布左侧，不侵占 600 像素场景区域。

## 验证

- 1920×1080 屏幕上的画布矩形应为 `QRect(1320, 312, 600, 768)`。
- 家园专项测试 92 项通过。
- 全量测试 656 项通过。
