# 午餐肉三套家园横向移动动画设计

## 目标

午餐肉在家园移动时，仅使用一套右向 16 帧动画并在向左时运行时镜像；原版、小恐龙套装、草莓小子套装分别使用与当前装备一致的动画。冰淇淋的家园移动资源保持不变。

## 资源结构

- `walk_right.png`：未装备套装时的午餐肉。
- `walk_right_dinosaur.png`：装备小恐龙套装时的午餐肉。
- `walk_right_strawberry.png`：装备草莓小子套装时的午餐肉。
- 每张资源均为 4×4、共 16 帧的透明 PNG，导入后统一为 1600×1600，每帧 400×400。
- 删除旧的 `walk_down.png`、`walk_up.png`、`walk_left.png`；左向不再保存重复图片。

## 运行逻辑

- 水平位移决定朝向：`dx > 0` 为右，`dx < 0` 为左。
- 纯纵向移动保持上一次左右朝向，避免角色突然切换到不存在的正面或背面素材。
- 右向直接绘制原帧，左向对同一帧镜像；完整 16 帧以既有 8 FPS 播放。
- `equipped_outfit` 通过套装定义中的 `home_walk_action` 选择动画；未装备时使用基础 `walk_right`。
- 商店成功装备或卸下套装后，立即调用现有家园窗口的 `refresh_pet_assets()`；只替换帧缓存，不重置位置或移动目标。
- 冰淇淋未声明横向网格，继续使用原生家园资源和既有回退链。

## 素材处理

- 导入脚本按每格 alpha 连通域保留主体，不再依赖橙色犬体筛选，因此绿色恐龙服和红色草莓服不会被误删。
- 输出前把 2560×2560 原图缩放到 1600×1600，满足画布和角色素材小于 2048 像素的约束。
- 每帧导入后检查非空和四边留白，防止动画裁切。

## 验证

- 定向回归：40 项通过，覆盖左右朝向、镜像、三套装备选择、16 帧加载和尺寸上限。
- 全量回归：656 项通过。
- 最终交付前继续执行 Python 编译、差异检查、源码启动与进程确认。
