# 家园固定脚印路线与对话气泡适配设计

日期：2026-08-10
状态：已实现并通过自动验证

## 背景与问题

当前 `HomeSceneWindow.navigation_feedback()` 每次绘制都从小狗的实时位置重新调用 `route_footprints()`。因此小狗移动后，尚未消失的脚印会重新采样、改变位置和间距，看起来像整条路线在跟着小狗滑动。

小屋对话气泡目前与室外共用同一套定位和配色。家园小狗采用固定前景尺寸并坐在地面区域，气泡需要在小屋状态下额外上移，并使用与奶油木质家园一致的视觉样式。右上角会在后续承载其他功能，本轮不增加气泡对右上角控件的避让逻辑。

## 目标

- 用户下达移动或手动睡觉指令时，一次性固定生成整条世界坐标脚印路线。
- 小狗前进时仅隐藏已经走过的脚印，未走过的脚印世界坐标保持不变。
- 新指令原子替换旧路线；抵达、装修、隐藏或退出时沿用现有清理与淡出生命周期。
- 将倾斜椭圆终点标记从约 `30px` 高缩小到约 `24px`，箭头同步收紧。
- 小屋对话气泡相对现有位置额外上移约 `24px`，并使用小屋专属暖色主题；室外气泡保持原样。

## 固定路线模型

场景新增一次性路线快照，至少保存：

- `start`：指令发出时的小狗世界脚底坐标。
- `end`：该指令的世界目标坐标。
- `footprints`：由 `route_footprints(start, end)` 生成的不可变脚印序列。

`command_home_pet()` 和 `toggle_home_sleep()` 成功建立手动目标后创建快照。`navigation_feedback()` 不再重新采样，只将快照内尚未经过的世界坐标转换为屏幕坐标。

## 已走过脚印判定

把小狗当前位置投影到快照的 `start -> end` 方向，得到路线进度。每枚脚印同样拥有相对起点的投影进度：

- 脚印进度小于或等于小狗进度加少量脚底容差时隐藏。
- 脚印进度大于该阈值时继续显示，且其原始世界坐标、旋转和镜像不变。
- 零长度路线不产生脚印，只保留终点反馈。

该判定允许小狗因帧步长略微越过某枚脚印，也不会让后方脚印重新出现。摄像机跟随后，路线会与整个世界画面一起平移，这是世界坐标固定的正常表现，不属于路线重排。

## 终点标记

- 椭圆素材继续保持原始约 `2.1:1` 宽高比，固定显示高度由 `30px` 调整为 `24px`。
- 呼吸缩放与轻微上下浮动继续保留。
- 箭头保持独立素材和原始比例，基础高度从 `31px` 收紧到约 `27px`，并贴近缩小后的椭圆。
- 到达后的 `350ms` 淡出保持不变。

## 小屋对话气泡

`SpeechBubble` 通过宠物窗口现有的活动家园接口判断当前是否在小屋：

- 小屋状态：在原有锚点公式基础上额外上移 `24px`。
- 室外状态：定位完全不变。
- 屏幕边缘裁剪仍然生效，保证气泡完整可见。
- 小屋主题使用奶油纸张渐变、浅桃木描边、暖棕文字和柔和阴影；尾巴继续指向小狗。
- 不调整快捷菜单、状态卡或右上角未来控件，也不新增与它们的碰撞避让。

## 测试策略

先写失败测试并观察 RED：

1. 小狗移动后，剩余脚印是首次快照的严格后缀，坐标、角度和镜像均不重排。
2. 新目的地会替换旧路线快照。
3. 终点椭圆基础高度约为 `24px`，宽高比保持素材比例。
4. 同一锚点下，小屋气泡比室外气泡上移 `24px`，且仍被屏幕边缘约束。
5. 小屋气泡渲染使用独立暖色主题，室外渲染保持原有颜色。

完成后运行相关 focused tests、完整 `pytest -q`、`py_compile` 与 `git diff --check`，再启动当前 worktree 的 `pet.py` 进行人工验收。
