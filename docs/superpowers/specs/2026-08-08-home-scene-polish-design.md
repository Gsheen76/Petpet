# 家场景装修界面优化设计

## 目标

根据验收截图优化装修态层级和主题一致性：装修时隐藏小狗，家具面板移到左侧并缩窄，双击小狗打开家，选中框采用家的暖色视觉。

## 交互

- 点击“装修”进入编辑态时临时隐藏小狗；点击“退出”离开编辑态时恢复小狗显示和置顶关系。
- 装修面板固定在家场景左侧，宽度约为画布三分之一，高度适配 900 x 768 画布；场景右侧保留主要背景和家具可视区域。
- 面板使用两列家具缩略图卡片，分类和收纳/放置操作保持可用；底部不再横向覆盖整个场景。
- 左键短双击小狗改为打开家场景；单次短点击继续抚摸，拖动行为不改变。
- 选中框使用暖棕色实线、轻微半透明填充、圆角边界和奶油色圆形控制点；旋转柄使用同一主题色，避免系统蓝色默认风格。

## 实现边界

- 不新增存档字段；小狗隐藏是运行时 UI 状态。
- 家具位置、缩放、旋转和装修状态继续使用现有 progression 字段。
- 装修面板命中区域、选中框命中区域和小狗双击计时均添加回归测试。
