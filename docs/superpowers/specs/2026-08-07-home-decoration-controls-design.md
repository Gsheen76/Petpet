# 家场景视野与装修控制设计

## 目标

扩展现有家场景，使玩家可以在横向房间内平移视野，并通过独立的装修模式收纳、放置和调整已购买家具。

## 交互

- 家场景左右边缘提供“左移”和“右移”按钮。点击立即移动一段距离，按住按钮则按固定步长持续移动；视野 X 坐标限制在 `0..900`。
- 右下角保留“退出”按钮，并在其左侧增加“装修”按钮。装修按钮只切换编辑状态，不改变家场景显示状态。
- 装修模式显示家具面板，分类为“全部、地毯、沙发、绿植、墙饰”。已拥有家具可以放置或收纳。
- 选中已放置家具后可拖动，并用“放大、缩小、左转、右转”控制缩放与旋转。退出装修后面板关闭，场景内点击不会改变家具。

## 状态与兼容

- `home_scene.viewport_x` 保存视野位置，`home_scene.decorating` 保存编辑模式。
- `home_stored_decorations` 保存已购买但当前收纳的家具。
- `home_decoration_transforms` 保存每件家具的 `scale` 与 `rotation`；旧存档默认缩放 `1.0`、旋转 `0`，已购买家具默认处于放置状态。
- 保留现有家具 ID、购买记录、世界坐标和边界校验；新资源只替换地毯和绿植贴图。

## 验收标准

- 左右按钮可点击和按住连续平移，松开后停止，且边界不越界。
- 装修模式可分类浏览已拥有家具，收纳后从场景消失，放置后恢复。
- 缩放、旋转和坐标在保存后重新打开家场景仍保持。
- 退出装修后拖拽、缩放、旋转均无效；退出家场景仍恢复普通桌面行为。
