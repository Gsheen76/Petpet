# Petpet 2D 分层骨骼方案

## 为什么改用 2D

Petpet 现有小狗拥有明确的大头、圆脸、大眼睛和柔软毛发风格。替换成通用
3D 模型会同时改变脸型、身体比例与材质，因此即使装扮跟随正确，也不再像原来的
小狗。2D 分层骨骼保留原画，只让拆分后的部件围绕固定挂点运动。

## 首版图层

所有图片使用相同画布尺寸、透明背景，并补全原本被遮挡的部分。

| 图层 | 绑定骨骼 | 用途 |
| --- | --- | --- |
| 尾巴 | `tail` | 摇尾、睡眠微动 |
| 后腿（左右） | `hind_leg_l` / `hind_leg_r` | 走路、扑球 |
| 身体 | `body` | 呼吸、整体起伏 |
| 前腿（左右） | `front_leg_l` / `front_leg_r` | 行走、玩耍 |
| 颈胸衔接 | `neck` | 遮住头身旋转产生的缝隙 |
| 头 | `head` | 点头、低头、左右轻摆 |
| 耳朵（左右） | `ear_l` / `ear_r` | 细微情绪动作 |
| 装扮 | 对应命名挂点 | 项圈绑定 `neck`，帽子绑定 `head` |

## 清单格式

`rig2d.py` 读取 JSON 清单。清单包含：

- `canvas`：统一画布尺寸；
- `bones`：父子骨骼、基准位置、旋转与缩放；
- `slots`：图片、图层顺序、骨骼、偏移和旋转中心；
- `animations`：帧率、循环方式和每根骨骼的关键帧。

关键帧之间由运行时线性插值。装扮使用普通 `Slot`，因此与身体部件共享完全相同的
骨骼变换，不需要为每张 PNG 单独猜坐标。

可填写的清单模板位于
[`docs/examples/rig2d-manifest.json`](examples/rig2d-manifest.json)。

## 接入顺序

1. 以 `assets/poses/idle.png` 为严格形象参考制作分层部件稿；
2. 检查重新组合后的静态图与原图是否一致；
3. 完成待机、行走、进食、睡眠、抚摸和玩耍关键帧；
4. 将红项圈绑定 `neck`，检查全部动作；
5. 验收后再让主窗口启用 2D 骨骼渲染，旧 PNG 动画始终保留为回退。

当前不应在分层原画尚未通过视觉检查前替换正式桌宠。
